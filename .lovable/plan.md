# ЦОР «Информация и компьютер» — 5 класс

Образовательная платформа на русском языке: 8 уроков, итоговый тест, личный прогресс ученика и панель учителя. Вход и хранение данных — через Lovable Cloud.

## Что получит пользователь

**Вход и роли**
- Регистрация и вход по email и паролю, при регистрации выбор роли: ученик или учитель.
- Ученик видит уроки, свой прогресс и тесты. Учитель дополнительно видит панель учителя.

**Навигация**
Главная · Уроки · Прогресс · Итоговый тест · Панель учителя (только для учителей).

**8 уроков**
1. Эргономика — посадка, экран, освещение, рабочее место.
2. Информация — текст, числа, графика, звук, видео, двоичный код 0 и 1.
3. Поиск в интернете — поисковые системы, ключевые слова, запросы.
4. Практика поиска — надёжность источников, фактчекинг.
5. История компьютеров — абак и счёты, первые ЭВМ, современные компьютеры.
6. Программное обеспечение и ИИ — системное, прикладное, инструментальное ПО, примеры ИИ.
7. СОР — тест из 10 вопросов с выставлением оценки.
8. ПО и ИИ: практическая работа — задания на применение.

Каждый урок: наглядная теория со схемами, встроенный видеоплеер, интерактивное упражнение (перетаскивание, сопоставление, сортировка), мини-тест для самопроверки. Результат сохраняется автоматически.

**Итоговый тест**
20 вопросов по всему курсу: баллы, процент выполнения, разбор каждой ошибки с правильным ответом.

**Прогресс ученика**
Шкала прохождения курса, отметки о пройденных уроках, оценки за мини-тесты, СОР и итоговый тест.

**Панель учителя**
Классы с кодом присоединения, список учеников, сводная таблица успеваемости, детальный просмотр ответов по СОР и тестам.

**Оформление**
Яркий дружелюбный дизайн для пятиклассников: крупные шрифты, тёплая палитра, карточки уроков с иконками; удобно на компьютере и планшете.

## Техническая часть

- Включается Lovable Cloud; email-вход активируется, регистрация с автоподтверждением, чтобы ученики входили сразу.
- Таблицы: `profiles` (имя, роль), `user_roles` (роли отдельной таблицей + функция `has_role`), `classes`, `class_members`, `lesson_progress`, `quiz_attempts` (тип: мини-тест / СОР / итоговый, баллы, ответы в JSON).
- RLS: ученик видит только свои записи; учитель — записи учеников своих классов; GRANT-ы для каждой таблицы.
- Контент уроков и банки вопросов — статические данные в коде (`src/content/`), результаты — в базе.
- Маршруты TanStack: публичные `/`, `/auth`; защищённые под `_authenticated`: `/lessons`, `/lessons/$id`, `/progress`, `/final-test`, `/teacher`.
- Чтение/запись прогресса — через server functions с проверкой авторизации; у каждого маршрута свои SEO-метаданные.
- Видео — встроенные плееры YouTube по подобранным ссылкам; если нужны конкретные ролики, пришлите их.

# Информатика для Пятиклашек

Создай ЦОР (цифровой образовательный ресурс) по информатике для 5 класса «Информация и компьютер» с поддержкой Lovable Cloud (Supabase) для авторизации и хранения данных.

Основные разделы и функции:
1. Авторизация и роли: отдельная регистрация/вход для ученика и учителя (роли student и teacher).
2. Навигация: Главная, Уроки, Прогресс, Итоговый тест, Панель учителя (доступна только учителям).
3. 8 структурированных уроков:
   - Урок 1: Эргономика (правильная посадка, экран, освещение, организация рабочего места, интерактивные задания).
   - Урок 2: Информация (виды информации: текст, числа, графика, звук, видео, двоичный код 0 и 1, практические задания).
   - Урок 3: Поиск в интернете (поисковые системы, формулирование запросов, ключевые слова).
   - Урок 4: Практика поиска (поиск информации, оценка надежности источников, фактчекинг).
   - Урок 5: История компьютеров (абак и счеты, первые ЭВМ, персональные и современные компьютеры).
   - Урок 6: Программное обеспечение и ИИ (системное, прикладное, инструментальное ПО, основы и примеры искусственного интеллекта).
   - Урок 7: СОР (Суммативное оценивание за раздел) — тест из 10 вопросов с фиксированием оценки.
   - Урок 8: ПО и ИИ: Практическая работа (задания на применение ПО и знакомство с ИИ-инструментами).
4. Структура каждого урока: интерактивная теория с понятными иллюстрациями/схемами, видеоматериал (встроенный плеер), интерактивное упражнение (drag-and-drop, сопоставление, сортировка), мини-тест для самопроверки и автоматическое сохранение результата.
5. Итоговый тест: 20 вопросов по всему курсу с подсчетом баллов, процентом выполнения и подробным разбором ошибок.
6. Прогресс ученика: личный кабинет с визуальной шкалой прохождения курса, пройденными уроками, оценками за СОР, мини-тесты и итоговый тест.
7. Панель учителя: управление классами, список учеников, сводная таблица успеваемости, детальный просмотр результатов тестов и ответов на СОР.
8. Интерфейс: современный, дружелюбный и красочный дизайн на русском языке, оптимизированный для пятиклассников, адаптивный для компьютеров и планшетов.

# Задачи

- [x] База данных: профили, роли, классы, прогресс, результаты тестов
- [x] Содержание 8 уроков + итоговый тест (20 вопросов)
- [x] Тема 8 переименована в «Программное обеспечение и искусственный интеллект»
- [x] Кнопка «Завершить урок» в каждой теме с сохранением прогресса
- [ ] Страницы: прогресс, панель учителя, оформление
- [ ] Регистрация ученика: фамилия, имя, класс, пароль; скрытый уникальный ID
- [ ] Однофамильцы в одном классе — разные аккаунты, вход с кодом активации
- [ ] Вход ученика на сервере (без показа технического логина)
- [ ] Отдельная кнопка «Учитель» с регистрацией и входом
- [ ] Учитель видит только учеников своих классов и их результаты по 8 темам
- [ ] Проверка базы, прав доступа и серверной логики

# Задачи

- [x] База данных: профили, роли, классы, прогресс, результаты тестов
- [x] Содержание 8 уроков + итоговый тест (20 вопросов)
- [x] Тема 8 переименована в «Программное обеспечение и искусственный интеллект»
- [x] Кнопка «Завершить урок» в каждой теме с сохранением прогресса
- [x] Страницы: прогресс, панель учителя, оформление
- [x] Регистрация ученика: фамилия, имя, класс, пароль; скрытый уникальный ID
- [x] Однофамильцы в одном классе — разные аккаунты, вход с кодом активации
- [x] Вход ученика на сервере (без показа технического логина)
- [x] Отдельная кнопка «Учитель» с регистрацией и входом
- [x] Учитель видит только учеников своих классов и их результаты по 8 темам
- [x] Проверка базы, прав доступа и серверной логики
